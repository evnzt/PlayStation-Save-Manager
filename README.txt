PlayStation Save Manager v1.0.0

A Windows application for managing PlayStation and PlayStation 2
memory cards, individual saves, save packages, PCSX2 folder cards,
and conversions across consoles and emulators.

-QUICK START-

Double-click Build-and-Launch.cmd.

The first build downloads a private .NET 8 SDK, publishes a
self-contained Windows x64 application inside the Publish folder,
and launches PSM.

Afterward, Launch.cmd opens the existing published application.

or

PlayStation Save Manager.exe in the Publish folder

-RELEASE BUILD-

Build-Release.cmd creates the self-contained application inside
the Publish folder without launching it.

-DATA-

Save Library:
%LocalAppData%\PlayStationSaveManager\SaveLibrary

Generated list icons and preview images:
%LocalAppData%\PlayStationSaveManager\Cache

The cache may be deleted safely and will be recreated when needed.

-FEATURES-

- PS1 and PS2 memory-card management
- Standard PS2, MemCard PRO2, and PCSX2 folder cards
- Verified save transfers and automatic backups
- New cards already formated, Save Card As, and folder conversion
- Universal Import Wizard and Universal Converter supporting individual saves and cards
- Game Save Library and Memory Card Library
- Native PS1 icons and animated PS2 previews
- Favorites, metadata, import, export, search, and deletion
